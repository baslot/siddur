# סידור — נוסח עדות המזרח

סידור מלא לאייפון (אפליקציית רשת למסך הבית) עם חיפוש לפי שם התפילה או לפי מילים מתוכה. עובד גם בלי אינטרנט.

**לפתיחה:** https://baslot.github.io/siddur/ → בספארי לוחצים על **שיתוף** ואז על **הוספה למסך הבית**.

## מקור הטקסט
סידור עדות המזרח, מהדורת תורת אמת (נחלת הכלל), דרך [ספריא](https://www.sefaria.org/Siddur_Edot_HaMizrach). הטקסט לא נערך ביד. הבנייה רק מנקה את הסימון: הוראות, כותרות ומילים מודגשות.
גופנים: Rubik ו־Frank Ruhl Libre ברישיון SIL Open Font License 1.1 (הרישיונות ב־`docs/fonts/`).

## בנייה
```sh
npm install
npm run fetch                 # מוריד את הסידור מספריא אל raw/
python3 scripts/make-icons.py # מצייר את הסמלים
npm run build                 # בונה את האתר אל docs/ (מכאן גיטהאב מגיש אותו)
node test/check.mjs           # בדיקה בכרומיום בגודל של אייפון
```
כל שינוי שנדחף ל־`docs/` מגיע לטלפון לבד בפתיחה הבאה.
